# AirNavFLOW (ใช้งานออฟไลน์ได้)

แอปวางแผนการบินที่ติดตั้งลงมือถือ/แท็บเล็ต/คอมได้ และใช้แผนที่ + GPS ได้แม้ไม่มีสัญญาณเน็ต

## มีอะไรใหม่
- **ติดตั้งเป็นแอป (PWA)** เปิดได้แม้ไม่มีเน็ต หลังจากเคยเปิดครั้งแรกตอนมีเน็ต
- **แผนที่ออฟไลน์ของเราเอง** ใช้ข้อมูล OpenStreetMap ทั้งประเทศไทยรวมไว้ในไฟล์เดียว `map/thailand.pmtiles`
  GitHub Actions เป็นคนสร้างไฟล์นี้ให้อัตโนมัติ เราไม่ต้องอัปโหลดเอง
- **ปุ่ม "ดาวน์โหลดแผนที่ลงเครื่อง"** ในแผง "แผนที่ออฟไลน์"
- **ข้อมูลความสูงออฟไลน์ (~150 ม.) + ชั้นเงาภูเขา (Hillshade)** ไฟล์ `map/elevation.pmtiles` สร้างโดย Actions เช่นกัน
- **บันทึกเส้นทางอัตโนมัติ** ปิดแอปแล้วเปิดใหม่ เส้นทาง ความเร็ว อัตราน้ำมัน และความสูงยังอยู่
- ไลบรารีทั้งหมด (Leaflet, JSZip, PMTiles, protomaps-leaflet) รวมอยู่ใน `airnavflow.html` ไฟล์เดียว ไม่ต้องโหลดจากเน็ต

## ติดตั้งขึ้น GitHub (ทำครั้งเดียว)
1. แตกไฟล์ zip แล้วอัปโหลด**ทุกไฟล์และทุกโฟลเดอร์**ขึ้น repo เดิม (ตัวแอปชื่อ `airnavflow.html`)
   - หน้า repo → **Add file → Upload files** → ลากไฟล์ทั้งหมดไปวาง → **Commit**
   - โฟลเดอร์ `.github` เป็นโฟลเดอร์ซ่อน บน Mac กด `Cmd + Shift + .` ใน Finder เพื่อให้เห็น
   - ถ้าลากโฟลเดอร์ `.github` ไม่ขึ้น: **Add file → Create new file** ตั้งชื่อ
     `.github/workflows/build-map-and-deploy.yml` แล้ววางเนื้อหาจากไฟล์นั้น
2. **Settings → Pages → Build and deployment → Source: `GitHub Actions`**
3. ไปแท็บ **Actions** จะเห็น "Build offline map and deploy" ทำงานเอง (ถ้าไม่เห็น กด **Run workflow**)
   - รอบแรกใช้เวลาหลายนาที เพราะต้องตัดแผนที่ไทยจากแผนที่โลก
   - เมื่อเสร็จ ในหน้าสรุปของรอบนั้นจะบอกขนาดไฟล์แผนที่
4. เปิดเว็บ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/airnavflow.html`

## ใช้งานบนมือถือ
1. เปิดเว็บด้วย **Safari (iPhone/iPad)** หรือ **Chrome (Android)** ตอนมี Wi-Fi
2. ติดตั้งลงหน้าจอ
   - iPhone/iPad: ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม** (ควรทำ ไม่งั้นระบบอาจลบข้อมูลที่โหลดไว้)
   - Android: เมนู ⋮ → **ติดตั้งแอป**
3. เปิดแอปจากไอคอน → แผง **แผนที่ออฟไลน์** → กด **ดาวน์โหลดแผนที่ลงเครื่อง** และ **ดาวน์โหลดข้อมูลความสูง** รอจนเสร็จ
4. ทดสอบก่อนบิน: เปิด **โหมดเครื่องบิน** (เปิด Location ไว้) → เปิดแอป → กด **GPS**

## สิ่งที่ใช้ได้ / ไม่ได้ เมื่อไม่มีเน็ต
| ใช้ได้ | ใช้ไม่ได้ |
|---|---|
| แผนที่ออฟไลน์ (OSM), GPS | ภาพดาวเทียม / แผนที่ถนน / ภูมิประเทศ (ออนไลน์) |
| สนามบิน, น่านฟ้า P/R/D/TRA, เส้นทาง ENR, VFR reporting points | ค้นหาสถานที่, ชื่ออำเภอของจุด |
| วางแผนเส้นทาง, ระยะ/เวลา/น้ำมัน, ไม้บรรทัด, KMZ | Windy |
| กราฟความสูง + Highest ELEV + เงาภูเขา (ถ้าโหลดข้อมูลความสูงแล้ว) | กราฟความสูงเส้นทางใหม่ (ถ้ายังไม่โหลดข้อมูลความสูง) |
| เส้นจังหวัด (ถ้าเคยเปิดตอนมีเน็ตแล้ว) | NOTAM ใหม่ (ต้องวางข้อความเอง ใช้ได้) |

> ความสูงคือ**ระดับพื้นดิน**เท่านั้น (ไม่รวมต้นไม้/อาคาร/เสา) ไม่ใช่ MSA

## ปรับขนาด/ความละเอียดแผนที่
แก้ในไฟล์ `.github/workflows/build-map-and-deploy.yml`
- `MAP_MAXZOOM: "12"` ระดับซูมสูงสุดที่เก็บ (11 = ไฟล์เล็กลง, 13 = ละเอียดขึ้นแต่ไฟล์ใหญ่ขึ้นมาก)
- `ELEV_MAXZOOM: "10"` ความละเอียดความสูง (10 ≈ 150 ม., 11 ≈ 75 ม. ไฟล์ใหญ่ขึ้น ~4 เท่า)
- `MAP_BBOX` กรอบพื้นที่ (ลองจิจูดต่ำสุด, ละติจูดต่ำสุด, ลองจิจูดสูงสุด, ละติจูดสูงสุด)
- แผนที่สร้างใหม่ทุกเดือนโดยอัตโนมัติเมื่อมีการ push หรือกด Run workflow
- ซูมเกินระดับที่เก็บไว้ได้ แผนที่จะขยายจากระดับสูงสุด (รายละเอียดไม่เพิ่ม)

## โครงสร้างไฟล์
```
airnavflow.html            ตัวแอป (รวมไลบรารีไว้ในไฟล์เดียว)
sw.js                      service worker (ทำให้เปิดออฟไลน์ได้)
manifest.webmanifest       ข้อมูลการติดตั้งแอป
icons/                     ไอคอนแอป
map/thailand.pmtiles       สร้างโดย GitHub Actions (ไม่ต้องอัปโหลด)
map/elevation.pmtiles      ข้อมูลความสูง สร้างโดย GitHub Actions
.github/workflows/         ขั้นตอนสร้างแผนที่ + เผยแพร่เว็บ
```
